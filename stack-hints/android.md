# Подсказки: Android (Kotlin / Java)

Заготовка для project.md → «Куда смотреть в коде». При настройке каждый путь проверить
`Glob`'ом в реальном репо: несуществующее выкинуть, найденное своё дописать. Пути даны для
типичного проекта; в многомодульном ищи по всем модулям (`**/`).

## Куда смотреть в коде

| Что нужно узнать | Куда смотреть |
|---|---|
| Версия приложения, `minSdk` / `targetSdk`, флейворы, build types, зависимости | `**/build.gradle(.kts)`, `gradle/libs.versions.toml` |
| Модули проекта | `settings.gradle(.kts)` |
| Разрешения, экраны (Activity), диплинки (`intent-filter`), `exported`, сервисы, ресиверы | `**/src/main/AndroidManifest.xml` |
| Экраны и навигация | Compose: `Grep "@Composable"` + навигационный граф (`NavHost`, `composable("…")`); View: `**/res/layout/*.xml`, `**/res/navigation/*.xml` |
| Тексты интерфейса и переводы | `**/res/values*/strings.xml` (новые строки без перевода в `values-<lang>` — кандидат в кейс локализации) |
| Сетевые запросы, эндпоинты, модели ответов | Retrofit: `Grep "@GET\|@POST\|@PUT\|@DELETE\|@PATCH"`; Ktor: `Grep "client.get\|client.post"`; модели — `Grep "@Serializable\|@SerializedName\|@Json"` |
| Обработка ошибок сети, таймауты, ретраи | OkHttp-интерцепторы (`Grep "Interceptor"`), `Grep "timeout"`, обёртки результата (`Result`, `sealed class …Error`) |
| Локальная БД и её миграции | Room: `Grep "@Database"` (номер `version`), `Grep "Migration("`, JSON-схемы в `**/schemas/`; SQLDelight: `**/*.sq`, `**/*.sqm` |
| Настройки и локальное хранилище | `Grep "DataStore\|SharedPreferences\|getSharedPreferences"` — ключи; переименование ключа = потеря данных при обновлении |
| Фиче-флаги и remote config | `Grep "RemoteConfig\|FeatureFlag\|featureToggle"` (подставь своё) |
| Фоновые задачи | WorkManager: `Grep "Worker\|WorkRequest"`; сервисы: `Grep "Service()"`, foreground service type в манифесте |
| Пуши | `Grep "FirebaseMessagingService\|onMessageReceived"`, каналы уведомлений (`NotificationChannel`) |
| Аналитика | `Grep "logEvent\|track("` (подставь свой трекер) — новые/изменённые события |
| Правила обфускации релизной сборки | `**/proguard-rules.pro`, `consumer-rules.pro`; `isMinifyEnabled` в gradle |
| DI — что с чем связано | Hilt: `Grep "@Module\|@Provides\|@Binds"`; Koin: `Grep "module {"` |
| Юнит-тесты | `**/src/test/**` |
| UI/инструментальные тесты | `**/src/androidTest/**` (Espresso, Compose UI Test) |

## Платформенные риски (для лупы platform и для кейсов типа `platform`)

Проверяй только то, что дифф реально задевает:

- **Жизненный цикл.** Поворот экрана и смена конфигурации (тема, язык, размер окна) —
  введённое не теряется, запрос не уходит повторно. Уход в фон и возврат. **Смерть процесса**
  в фоне и восстановление (`SavedStateHandle`, `rememberSaveable`) — состояние на месте,
  а не белый экран или падение.
- **Разрешения.** Первая выдача, отказ, «больше не спрашивать», отзыв в настройках на лету.
  Android 13+: разрешение на уведомления (`POST_NOTIFICATIONS`). Фото и файлы — на новых
  версиях частичный доступ к медиа.
- **Версии ОС.** API новее `minSdk` без проверки версии — падение на старых. Изменения
  поведения при повышении `targetSdk` (фоновые запуски, foreground service types,
  exact alarms, broadcast'ы).
- **Экраны.** Маленький экран, планшет, складной, крупный шрифт (`font_scale` 1.3+), тёмная
  тема, вырезы, жесты навигации, клавиатура поверх полей.
- **Сеть.** Офлайн на входе и посреди операции, смена Wi-Fi ↔ мобильная, медленная сеть,
  повтор после восстановления — без дублей и без вечного лоадера.
- **Обновление поверх старой версии.** Миграция локальной БД (есть ли `Migration` на
  каждый шаг версии, нет ли `fallbackToDestructiveMigration` — тихой потери данных),
  переименованные ключи настроек, изменённый формат кэша. Кейс: поставить прошлую версию
  из магазина/CI, набить данные, обновить до сборки задачи.
- **Совместимость с бэкендом.** Старые версии приложения продолжают ходить в обновлённый
  API; новое приложение — в ещё не обновлённый бэкенд (если релизы не синхронны).
- **Пуши и диплинки.** Приложение убито / в фоне / открыто; диплинк на экран, требующий
  входа; диплинк с битыми параметрами.
- **Фон.** Doze и ограничения батареи, WorkManager после перезагрузки, у производителей
  с агрессивной экономией батареи — задачи не выполняются.
- **Релизная сборка.** R8/ProGuard вырезает классы моделей и ломает сериализацию —
  проверять на release-like сборке, а не только на debug.
- **Доступность.** `contentDescription` у иконок-кнопок, размер нажимаемой зоны, TalkBack
  читает осмысленно.
