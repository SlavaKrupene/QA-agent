# Подсказки: общий случай (бэкенд, веб, прочие стеки)

Заготовка для project.md → «Куда смотреть в коде», когда под стек нет своего файла. При
настройке переведи каждую строку в реальные пути репо (проверь `Glob`'ом) и выкинь лишнее.
Для iOS / Flutter / React Native можно по образцу [android.md](android.md) завести свой
файл — это полезная адаптация.

## Куда смотреть в коде

| Что нужно узнать | Где обычно искать |
|---|---|
| Стек, версии, зависимости | манифест сборки: `package.json`, `pom.xml`, `build.gradle`, `go.mod`, `pyproject.toml`, `composer.json`, `Gemfile`, `*.csproj` |
| Эндпоинты API, права на них | файлы роутинга / контроллеры / аннотации маршрутов; middleware / фильтры авторизации |
| Схема БД, индексы, NOT NULL, уникальность | **миграции** (а не модели): `migrations/`, `db/migrate/`, `resources/db/`, `*.sql` |
| Перенос старых данных (backfill) | миграции + поиск по `UPDATE`, массовым обновлениям в скриптах |
| Где используется X | поиск по исходникам (`Grep`) |
| Конфиги, env-переменные, фиче-флаги | `.env.example`, `config/`, `application*.yml`, `settings*.py`, шаблоны деплоя (helm, k8s, compose, CI) |
| Фоновые задачи, очереди, расписание | воркеры/джобы/консьюмеры, cron-описания, планировщик |
| Внешние интеграции | клиенты внешних API, вебхуки, их обработка ошибок и ретраи |
| Тексты ошибок и локализация | файлы переводов, константы сообщений |
| Веб-фронт: экраны, маршруты, формы | роутер, страницы/компоненты, схемы валидации форм |
| Тесты | `tests/`, `test/`, `spec/`, `__tests__/`, `*_test.*`, `*.spec.*` |

## Риски, которые легко пропустить

- Совместимость API: старые клиенты с новым сервером и наоборот.
- Миграция на большой таблице: блокировки, время, откат.
- Идемпотентность: повтор запроса, двойной клик, повтор джобы после падения.
- Часовые пояса и границы суток/месяца.
- Права: пользователь А подставляет id объекта пользователя Б.
- Кэш: старые данные после изменения логики.
- Веб: браузеры, адаптивность, возврат «назад», обновление страницы посреди процесса.
